# Design Practices Applied

This project applies the design practices referenced by the screenshots in a product-focused way:

- Frontend polish: clear interaction states, responsive controls, canvas-safe sizing, focus styles, and reduced-motion support.
- Web UI guidelines: primary action is obvious, labels are short, controls stay close to the drawing surface, and status/error copy is actionable.
- Motion design: hover/press feedback is subtle and disabled for users who prefer reduced motion.
- Design critique: camera permission is no longer requested on page load; the user starts it intentionally, reducing failure and confusion.
- Landing-page thinking: the first viewport shows the actual product experience, not a marketing page.

The app remains a functional hand-tracking drawing tool rather than becoming a landing page.
